# 投标标书检查清单

## 一、基础信息与格式规范

| 优先级 | 检查项目 | 检查要点 | 状态 | 备注 |
|--------|----------|----------|------|------|
| ★★ | 项目名称与编号 | 标书封面、正文、页眉页脚中的项目名称、项目编号与招标公告完全一致，无错别字 | ✅ | 一字之差可能导致废标 |
| ★★★ | 投标人名称 | 公司名称与营业执照完全一致；联合体投标需列明所有成员名称及牵头人 | ✅ | 含括号、括号内文字 |
| ★★ | 签字盖章 | 逐页检查；法定代表人签字或盖章、公司公章、骑缝章；签字人与授权书一致 | ☑️ | 漏签漏盖=废标 |
| ★★ | 密封与封装 | 正本/副本数量符合要求；正本封面标注"正本"；密封条加盖公章；电子标书U盘单独封装 | ✅ | 按招标文件要求 |
| ★★★ | 目录与页码 | 目录页码与正文页码一致；页码连续无断页；目录层级清晰 | □ | 更新后需重新核对 |
| ★★ | 排版与字体 | 字体、字号、行距、页边距符合招标文件要求；图表清晰可读 | □ | 部分招标有严格格式 |
| ★ | 文件格式 | 纸质版双面/单面打印符合要求；电子版为PDF或指定格式；文件大小符合上传限制 | □ | |

## 二、商务部分

| 优先级 | 检查项目 | 检查要点 | 状态 | 备注 |
|--------|----------|----------|------|------|
| ★★★ | 投标函/报价函 | 金额大小写一致；报价币种正确；工期/交货期/服务期符合要求；无涂改痕迹 | ✅ | 核心商务条款 |
| ★★★ | 投标保证金 | 金额正确；缴纳方式符合要求（电汇/保函/保险）；到账时间截止前；凭证复印件附后 | ✅ | 未缴纳=废标 |
| ★★★ | 法定代表人授权书 | 授权人与被授权人信息准确；授权期限覆盖投标有效期；签字盖章齐全 | ✅ | 附身份证复印件 |
| ★★ | 营业执照 | 在有效期内；经营范围覆盖投标内容；副本复印件加盖公章 | ✅ | 三证合一 |
| ★★★ | 资质证书 | 资质等级满足要求；证书在有效期内；证书编号可查询验证 | ✅ | 如ISO、行业资质等 |
| ★★ | 业绩证明 | 合同金额、时间、内容符合要求；提供合同关键页/验收证明；甲方联系人及电话真实 | ✅ | 近3年/5年要求 |
| ★★ | 财务状况 | 审计报告年份符合要求；资产负债率、利润等指标满足门槛；由会计师事务所出具 | ✅ | 近年财务审计 |
| ★★ | 信用记录 | 信用中国/信用地方无严重失信记录；中国政府采购网无重大违法记录；截图日期临近开标日 | ✅ | 开标前3-5天内查询 |
| ★★ | 纳税与社保 | 近3个月或6个月纳税证明和社保缴纳证明；体现公司正常运营 | ✅ | 部分项目强制要求 |
| ★★ | 联合体协议 | 如为联合体：分工明确、责任清晰、各方签字盖章、牵头人授权 | ☑️ | 非联合体忽略 |
| ★ | 分包承诺 | 如不允许分包：提供非分包承诺函；如允许：列明分包单位及资质 | ✅ | |
| ★★ | 技术部分 | 逐条响应招标文件技术参数；无偏离/正偏离/负偏离标注清晰；无复制粘贴痕迹 | ✅ | ★号条款必须满足 |
| ★★★ | 技术响应表 | 方案架构、实施计划、人员配置、质量保证、售后服务、培训计划等章节齐全 | ✅ | 对照评分标准 |
| ★★ | 项目团队人员 | 人员数量、资质、经验满足要求；提供简历、证书、社保缴纳证明；人员不重复任职 | ✅ | 关键人员不可替代 |
| ★★ | 实施计划/工期 | 工期符合要求；里程碑节点合理；甘特图或横道图清晰；与人员配置匹配 | ✅ | 防止货不对板 |
| ★★ | 设备/产品清单 | 品牌、型号、规格、数量与报价一致；提供彩页或技术白皮书；满足招标文件参数 | ✅ | |

## 三、报价部分

| 优先级 | 检查项目 | 检查要点 | 状态 | 备注 |
|--------|----------|----------|------|------|
| ★★★ | 报价一致性 | 投标函报价 = 报价明细表总价 = 分项报价表合计；大小写金额一致 | ✅ | 不一致=废标风险 |
| ★★★ | 报价明细 | 分项报价完整；无漏项；单价×数量=合价；税率、税费计算正确 | ✅ | 增值税专票/普票 |
| ★★ | 报价合理性 | 明显低于其他投标人需准备书面说明；不得低于成本价；符合预算控制价 | ✅ | 防止恶意低价 |
| ★★ | 币种与单位 | 报价币种为人民币；计量单位统一（万元/元）；保留小数位数符合要求 | ✅ | |

## 四、评分响应与偏离

| 优先级 | 检查项目 | 检查要点 | 状态 | 备注 |
|--------|----------|----------|------|------|
| ★★★ | 评分标准逐条响应 | 对照评分表，确保每一分都有对应证明材料；商务、技术、报价分均有支撑 | ✅ | 制作评分索引表 |
| ★★★ | ★号条款（关键条款） | 所有带★号的条款必须完全满足；提供相应证明材料；无负偏离 | ✅ | 不满足=废标 |
| ★★ | 偏离表填写 | 逐条列明偏离情况；无遗漏条款；无复制招标文件原文作为响应 | ✅ | 如实填写 |
| ★★ | 证明材料索引 | 制作证明材料索引表，方便评标专家快速查找；页码标注准确 | ✅ | 提升评标体验 |

## 五、递交前最终检查

| 优先级 | 检查项目 | 检查要点 | 状态 | 备注 |
|--------|----------|----------|------|------|
| ★★★ | 开标时间与地点 | 确认开标日期、时间、地点；预留充足交通时间；携带原件备查 | □ | 迟到=拒收 |
| ★★★ | 原件备查 | 按招标文件要求准备原件（资质证书、业绩合同、人员证书等）；原件清单核对 | □ | 部分项目现场核验 |
| ★★★ | 电子标书检查 | CA数字证书有效；电子标书成功上传并解密测试；PDF可正常打开；文件无损坏 | □ | 电子标需提前测试 |
| ★★ | 备份文件 | 准备电子版备份（U盘、网盘）；纸质版多备一份应急；投标文件最终版存档 | □ | 防突发情况 |
| ★★ | 废标条款自查 | 逐条核对招标文件中的废标条款，确保无任何一项触碰 | □ | 红线意识 |
| ★ | 投标有效期 | 投标函承诺的有效期符合招标文件要求（通常90/120/180天） | □ | |
| ★ | 招标文件澄清 | 是否已查看所有答疑澄清文件；标书内容是否按最新澄清调整 | □ | 发布后需同步更新 |
